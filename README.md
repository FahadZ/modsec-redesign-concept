# Modern Security Systems - concept redesign

A four-page static site: Home, Packages, Products, Contact. No framework or server needed.

## View it
Open `docs/index.html` in a browser (fonts load from Google Fonts, so an internet connection helps).

## Edit it
Source lives in `src/` and is assembled into `docs/` by a tiny build script.

```bash
node build.mjs
```

- `src/pages/*.html` - page content
- `src/partials/` - shared header, footer and icon sprite
- `docs/assets/styles.css` and `docs/assets/app.js` - styles and behaviour

Design system: "Trust & Authority" from the ui-ux-pro-max skill, using the current brand navy and the logo's yellow, Poppins + Open Sans.

## Images
All images are original SVG illustrations (27 files, about 80 KB total) in `docs/assets/img/`, generated by `tools/gen-images.mjs`:

- `cam-*.svg` - CCTV-style live views (front entrance, driveway, loading dock, storefront). The LIVE badge and ticking timestamp are HTML overlays.
- `bundle-*.svg` - one scene per bundle.
- `product-*.svg` - the 16 catalogue items, plus `lifesentry.svg`.

They are illustrations, not photos. For launch, real photos of the owner's own installs will be more credible: drop them in `docs/assets/img/` and point the `<img src>` at them. (Do not reuse photos from the old site without the photographer's permission.)

To tweak the artwork, edit `tools/gen-images.mjs` and run `node tools/gen-images.mjs`.

## Placeholders the owner needs to confirm (all marked in the pages)
- **Company history (Our story page)** - "since 1975" comes from Rob Racine's LinkedIn profile, as reported by the person who commissioned the concept. Confirm it is the company's founding year (not, say, the start of his career), then fill in the founding story, milestone years, bio, photos and team. The old site's "35+ years" was replaced by "50+ years".
- **Every price** (`$XX`, `$XXX`), savings amounts, and the monthly/annual billing note.
- **Plan features, bundle contents, add-ons and membership benefits** - I invented sensible starting points; none come from the owner.
- **Product catalogue** - names, brands (`[Brand]`), prices, photos. Only Honeywell and LifeSentry come from the original site.
- **Logo** - a placeholder shield mark; swap in the real logo file.
- **Photos and videos** - illustrations are used for now (see Images). The original stock photo is not reused. The three video thumbnails are placeholders for the existing product videos.
- **Credentials** - add BBB / CANASA / licence numbers where marked.
- **Office hours, reply time, charity promotion details, LifeSentry offer, typical price range (FAQ).**
- **Google Maps embed and Google reviews rating.**
- **Article pages** - three topic cards; only the first matches an existing article.
- **Forms** - the contact/quote form is a front-end demo and sends nothing. Connect it to email or a CRM.
- **Customer portal / pay-your-bill** - shown as "coming soon".
- **Privacy policy** page and link.

## Hosting (GitHub Pages)
The repo publishes the `docs/` folder from the `main` branch (Settings -> Pages -> Deploy from a branch -> `main` / `/docs`). To update the live site: edit `src/`, run `node build.mjs`, commit and push.

Because this is a concept for a real business, every page carries a "not the official website" banner, `noindex` and a `robots.txt` that blocks crawlers. Remove those only when the owner approves going live.

## Before going live
Host over HTTPS, add a real form backend, and replace all placeholder content.
